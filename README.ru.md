# brullik-bybit-grid-bot-research

Документация и целевая архитектура высокопроизводительной системы исследования и live-работы с Bybit Futures Grid Bot.

> **Состояние репозитория:** только архитектура, управление и планирование. В стартовом пакете нет торгового кода.

[English version](README.md)

## Финальная цель

Создать промышленную, проверяемую и fail-closed систему, которая:

1. рассчитана на **700 инструментов × 10 лет × таймфрейм 1m**;
2. эффективно обрабатывает около **3,68 млрд торговых 1m-свечей**, а при параллельном хранении mark-price 1m — около **7,36 млрд строк свечей**;
3. находит горизонтальные проторговки, подбирает параметры нативного Bybit Futures Grid Bot в режиме **Neutral + Geometric** и проверяет их без lookahead;
4. допускает к live только неизменяемый, полностью провалидированный пакет стратегии;
5. позволяет запускать **скачивание истории**, **исследование/подбор параметров** и **live** как отдельные приложения;
6. позволяет запустить только live-приложение без исторического хранилища, оптимизатора и исследовательских зависимостей;
7. после прохождения гейтов безопасно валидирует, создаёт, контролирует, восстанавливает состояние и закрывает сетки через Bybit API.

Фраза «700 инструментов × 10 лет» задаёт ёмкость и целевой горизонт системы. Реальная история каждого инструмента начинается с фактической даты листинга и заканчивается делистингом. Заполнять несуществующую историю искусственными свечами запрещено.

## Независимые режимы запуска

| Приложение | Назначение | Торговые ключи | Нужна вся история |
|---|---|---:|---:|
| `grid-data` | Массовая загрузка, REST-дозагрузка, нормализация, аудит качества, compaction | Нет | Записывает её |
| `grid-research` | Признаки, кандидаты, outcomes, подбор параметров, backtest, robustness | Нет | Да, только чтение |
| `grid-live` | Текущий рынок, сигналы, риск, подтверждения, исполнение и reconciliation | Да | Нет |
| `grid-release` | Сборка, проверка, promotion и revoke пакетов стратегии | Нет | Только результаты research |

Live загружает только один promoted strategy bundle и небольшой rolling-window текущих данных. Он не имеет права импортировать research orchestration, сканировать многомиллиардную историю или менять research-артефакты.

## Ключевые решения для скорости

- сначала официальные bulk-архивы; REST используется для свежих данных и ремонта дыр;
- Parquet + ZSTD, сортировка по instrument/time;
- месячные временные разделы и небольшое число hash-buckets вместо десятков тысяч маленьких symbol-партиций;
- DuckDB для SQL, каталогов и аудитов;
- Polars Lazy API, predicate/projection pushdown, многопоточность и streaming;
- признаки вычисляются и материализуются один раз;
- дорогая симуляция выполняется по разреженному набору кандидатов, а не по всем свечам и всем параметрам;
- каждый shard детерминирован, повторяем и имеет receipt;
- datasets неизменяемы после commit marker;
- полный прогон 700 × 10 лет запрещён до прохождения benchmark gate.

## Текущая продуктовая база

- Bybit, linear USDT perpetual.
- Сигналы на 1m.
- Горизонтальные проторговки.
- Native Futures Grid Bot: Neutral + Geometric.
- Стартовая гипотеза капитала: 500 USDT.
- Максимальный плановый убыток одной сетки: 5 USDT.
- Trailing up/down в V1 выключен.
- На symbol не более одной активной сетки.
- Первые реальные запуски — только с ручным подтверждением.
- Emergency stop обязателен; новые входы остаются запрещены до `/resume`.

Это контролируемые предположения, а не обещание доходности. Изменять их можно только через change control и зарегистрированное решение.
